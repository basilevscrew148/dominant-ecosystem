# Выводы по всем чатам и статьям

> Изучен корпус: **1027 документов** (568 заметок vault, 107 расшифровок чатов, 352 файла библиотеки, 174 МБ) + поиск по сети. Ниже — что уже реализовано, какие приёмы повторяются, и какие пробелы закрывает экосистема «Доминанта».

## 1. Что vault уже реализует (де-факто контур Ухтомского)

Заметки пользователя уже сшили Ухтомского в связный каркас — до этого проекта:

- **Доминанта = физиология внимания** (`30-Concepts/нейронаука-внимания.md`): сети Posner–Petersen = режимы доминанты; метапознание = «какая доминанта у руля».
- **Доминанта → диалогизм** (`30-Concepts/диалогизм-и-семиотика.md`): «заслуженный собеседник» vs «Двойник»; петля рефлексии = диалог «я ↔ я-как-другой».
- **Терминологический мост советское↔западное** (`20-Permanent/карта-терминологии...`): доминанта↔salience; собеседник↔theory of mind; Бернштейн↔predictive coding.
- **Этика диалога** (`30-Concepts/генрих-батищев-глубинное-общение.md`): собеседник как условие рефлексии.

**Вывод:** основание готово; не хватало только (а) явного инструмента, (б) научной упаковки, (в) единой карты. Это и есть данный проект.

## 2. Повторяющиеся приёмы в чатах (методология пользователя)

По 107 чатам виден устойчивый «почерк»:

1. **Мета-исследовательские промпты** («Ты — исследователь. Собери научные работы…»): многоагентная/мультисорсовая добыча + paper_search + sci-hub.
2. **«Метод → плагин»**: LibGen, YouTube transcript, browser-bridge, корректор опечаток, «Линия жизни», V-диаграммы — методы, превращённые в DSH-инструменты.
3. **SRS/Anki** как ядро закрепления (auto-cards, колоды по языкам/физиологии).
4. **Гибридный поиск** (kb-hybrid, семантика + BM25) как способ «притянуть релевантное».
5. **Цели/отчёты** (goal + progress-отчёты по готовности файлов) — удержание длинных задач.
6. **Планирование/рефлексия** (session-contract, reflection, daily/weekly) — хронотоп (прошлое→будущее).

**Вывод:** пользователь *уже действует по принципу доминанты интуитивно* (держит цель, суммирует, итерирует, сверяется). Новые скиллы лишь делают этот неявный протокол явным и переиспользуемым.

## 3. Пробелы (что закрывает проект)

| Пробел (найдено) | Чем закрыт |
|---|---|
| «Хронотоп» в vault отсутствовал (единственное вхождение — моя новая заметка) | серия + книга, хронотоп-промпт |
| Нет инструмента, кодирующего *доминанту* как логику | скилл `dominant` |
| «Собеседник» есть как *идея*, но не как *операция обзора* | скилл `sobesednik` |
| Нет явного «мета-промпта» (самоописания исследования) | промпт `мета-промпт` |
| research-pipeline не удерживает доминанту и не зовёт собеседника | улучшение скилла |
| Нет научной упаковки (статьи/книга) | серия + magnum opus |

## 4. Ключевой вывод

**Экосистема = интуитивный протокол пользователя, сделанный явным.** Доминанта Ухтомского — не новая тема в vault, а **имя того, что пользователь уже делает**; поэтому новые инструменты не «навязаны», а **вырастают из уже существующего опыта**. Холистический принцип: не плодить фичи, а дать одному инварианту (7 операций доминанты) проявиться на всех четырёх слоях.
