# dominant-rs

Исполняемая формальная модель доминанты А. А. Ухтомского на Rust (std-only, без внешних зависимостей).

## Уравнение (статья 07, v1.1 — после кросс-валидации)

```
x_i(t+1) = tanh( ρ·x_i + w·max(x_i,0) + π_i·s_i·(1 + g_i·𝟙[i=goal]) + γ·g_i·(T − x_i)·𝟙[i=goal]
                 − κ·max(x_L,0)·𝟙[i≠L] + ε_i )
π_i = π₀ + α·max(x_i,0)
```

| Параметр | Смысл | Источник |
| --- | --- | --- |
| `π₀`, `α` | precision-weighting | гипотеза Радченко |
| `ρ` | инерция | свойство 1 (Шульгина) |
| `w` | само-возбуждение (бистабильность при ρ+w>1) | свойство 2 «повышенная возбудимость» |
| `κ` | сопряжённое торможение | свойство 4 |
| `γ`, `T` | тяга хронотопа (работает и без стимула) | доминанта + хронотоп |
| `tanh` | насыщение (без него модель расходится) | предел частоты разряда |

## Компоненты

- `src/lib.rs` — ядро (динамика, доминанта, ГПСЧ) + 4 юнит-теста;
- `src/main.rs` — демо и сценарии `--scenario v1|v2 [--chrono]` (зеркала `dominant_sim.py` / `dominant_sim2.py`, печатают `FINAL`/`MID`);
- `src/bin/predictions.rs` — проверка 5 предсказаний статьи 07 по сеткам параметров.

## Запуск

```powershell
cargo test --release
cargo run --release --                     # демо
cargo run --release --bin predictions      # П1–П5
python ..\cross_validate.py                # кросс-валидация ↔ Python-симуляции (из папки ops/)
```

## Статус предсказаний (2026-11-26)

- П2 (ρ+w > 1 — устойчивость), П3 (хронотоп компенсирует salience), П4 (парковка монотонна), П5 (порог κ «прилипания») — **подтверждены**.
- П1 (латентность ↓ с α) — **опровергнуто, уточнено**: precision-weighting сам по себе не ускоряет селекцию (симметрично ускоряет и конкурента); селекцию ускоряет сопряжённое торможение κ.
