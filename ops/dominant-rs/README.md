# dominant-rs

Исполняемая формальная модель доминанты А. А. Ухтомского на Rust (std-only, без внешних зависимостей).

## Гипотезы (уровень D → проверяемые предсказания)

| Гипотеза | Реализация в коде | Предсказание |
| --- | --- | --- |
| Доминанта ≈ precision-weighting | `attention_gain`: возбуждение повышает precision канала | С повышением `attention_gain` латентность захвата доминанты падает монотонно |
| Инерция возбуждения | `inertia` (доля сохранения за шаг) | При `inertia → 0` доминанта не удерживается при конкурирующем шуме |
| Хронотоп-антиципация | усиление `goal_relevance` для целевого канала | При фиксированном шуме время разрешения растёт с ростом числа «чужих» стимулов; цель с низкой salience всё равно побеждает при достаточной инерции |

## Запуск

```powershell
cargo run -- --steps 60 --seed 7 --goal 2
cargo test
```

## Сопоставление с 7 операциями доминанты

| # | Операция | В коде |
|---|---|---|
| 1 | Поставить очаг | аргумент `--goal` |
| 2 | Суммировать | накопление `inertia·x + inputs` |
| 3 | Затормозить конкурентов | `lateral_inhibition` от лидера |
| 4 | Держать инерцию | параметр `inertia` |
| 5 | Задать хронотоп | `chronotope_boost` + событие разрешения `resolved_at` |
| 6 | Проверить собеседником | вне ядра (роадмап: внешний критик) |
| 7 | Мета-наблюдать | лог доминанты на каждом шаге + парковка `parking` |
