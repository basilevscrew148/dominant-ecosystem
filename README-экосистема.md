# Экосистема «Доминанта»

> **Одна логика — четыре слоя.** Принцип доминанты А. А. Ухтомского (господствующий очаг: притягивает релевантное, тормозит конкурентов, инерционен, антиципирует разрешение) переводится из физиологии в **базовую логику агента и инструмента**, а вокруг него строится целостная экосистема знания и мышления.

## Что это и зачем

Это не «ещё один плагин», а **холистическая система**, где теория, промпты, инструменты и пользовательский опыт сцеплены одним принципом. Позиция: методы мышления — не отдельные фичи, а **слои одной архитектуры**, как сети внимания Posner–Petersen суть «режимы» одной доминанты.

## Четыре слоя

| Слой | Что это | Артефакты |
|---|---|---|
| **1. Метод (теория)** — «почему» | Идеи Ухтомского + смежные (Бахтин, Фристон, Бернштейн, Батищев, Левинас) | научная серия + большая статья, книга-magnum opus |
| **2. Логика (промпты/скиллы)** — «как» | Принцип доминанты как протокол действий агента | скиллы `dominant`, `sobesednik`; библиотека промптов |
| **3. Инструменты (код)** — «чем» | DSH-плагины/инструменты, исполняющие протокол | существующие (kb-hybrid, six-hats-panel, research-pipeline, synthesize…) + новые |
| **4. Опыт (экосистема)** — «каково пользоваться» | Карта взаимосвязей, путь пользователя, мета-промпт | этот README, глоссарий, индексы |

## Единый принцип (ядро)

**Доминанта** = `фокус (цель) + суммация (притяжение релевантного) + сопряжённое торможение (паркинг конкурентов) + инерция (удержание) + хронотоп (антиципация разрешения) + собеседник (анти-Двойник) + мета-наблюдение (кто у руля)`.

Этот набор из 7 операций — инвариант, который повторяется на всех слоях:

- в **теории**: доминанта ↔ selective attention/precision-weighting; собеседник ↔ theory of mind/диалогизм; хронотоп ↔ «модель потребного будущего» (Бернштейн) ↔ predictive coding;
- в **промпте**: те же операции — команды агенту (сформулировать доминанту, затормозить лишнее, удержать, антиципировать, проверить у собеседника, наблюдать себя);
- в **инструменте**: скилл/плагин, который *физически* исполняет операции (например, `dominant` удерживает фокус через todo/цель, `sobesednik` запускает критический обзор, kb-hybrid суммирует релевантное из базы).

## Инвентарь (что уже есть → что добавлено)

**Существующее (базовый контур, уже в профиле):**
- `kb_search` / `kb_semantic` / `kb-hybrid` — **суммация**: притяжение релевантного из базы.
- `six-hats-panel` / `six_hats` / `pmi` / `po` / `water_logic` — параллельные «режимы доминанты».
- `recursive-thinking` / `reflect` — **инерция/итерация** до аттрактора.
- `research-pipeline` / `synthesize` / `writer` / `auto-cards` — превращение материала в знание.
- `verify-claims` / `calibrated-reasoning` — анти-Двойник (проверка).
- `session-contract` / `incident-log` / `reflection` — **хронотоп** (память о прошлом/плане будущего).

**Добавлено (этот проект):**
- Скилл **`dominant`** — явно кодирует 7 операций доминанты как протокол агента.
- Скилл **`sobesednik`** — «заслуженный собеседник»: критический обзор/prior-art-проверка против «Двойника».
- **Научная серия** (4 статьи) + **большая обзорная статья**.
- **Книга «Доминанта»** (magnum opus).
- **Библиотека промптов** (`доминанта-исследователь`, `собеседник-рецензент`, `хронотоп-планировщик`, `мета-промпт`).
- **Улучшения** существующих скиллов (research-pipeline: шаг «доминанта + собеседник»).

## Путь пользователя (опыт)

1. **Войти с вопросом** → сформулировать доминанту (одна цель, одно предложение) — скилл `dominant` или промпт.
2. **Суммировать** — гибридный поиск по базе (kb-hybrid) притягивает релевантное.
3. **Исследовать/писать** — research-pipeline / writer под удержанием доминанты (не расползаться).
4. **Проверить** — `sobesednik` (заслуженный собеседник) ловит само-проекцию и пробелы; verify-claims.
5. **Зафиксировать** — заметка + Anki; session-contract/reflection — хронотоп: что было, что будет.
6. **Мета-шаг** — `recursive-thinking`/`dominant`-наблюдение: какая доминанта была у руля и куда ведёт.

## Холистический принцип (итог)

Экосистема сильна **не суммой инструментов, а их взаимным усилением через один инвариант**. Каждый инструмент — частный случай доминанты; потому они не конфликтуют, а складываются в один опыт: *держать фокус, притягивать нужное, тормозить лишнее, антиципировать, сверяться с собеседником и видеть себя*.
