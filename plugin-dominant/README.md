# @local/dominant

DSH host-плагин: кодирует **принцип доминанты** (А. А. Ухтомский) как инструмент агента.

## Что делает

Регистрирует инструмент `dominant`, который хранит **постоянное состояние доминанты** в файле `D:\Knowledge\dominant-state.json`:

- `goal` — текущая господствующая цель (одно предложение);
- `chronotope` — целевое состояние (что будет верно при разрешении);
- `parking` — список отложенного (сопряжённое торможение).

Состояние **переживает сессии** (в отличие от скилла, который живёт только в контексте).

## Использование

- `dominant { action: "get" }` — прочитать текущую доминанту.
- `dominant { action: "set", goal: "…", chronotope: "…", parking: ["…"] }` — установить/обновить.
- `dominant { action: "clear" }` — сбросить.

## Связь с экосистемой

Пара к скиллам `dominant` (протокол из 7 операций) и `sobesednik` (проверка собеседником): скилл даёт *логику*, этот плагин — *живое состояние*.
