# Доминанта, установка и контекст LLM: три масштаба одной преднастройки

> **Аннотация.** Установка (Узнадзе), доминанта (Ухтомский) и «размывание внимания» в контекстных окнах LLM описывают **один феномен на трёх временны́х масштабах**: восприятие/поведение определяется предварительным состоянием, а не стимулом. Показано, что (а) установка = мгновенная преднастройка, доминанта = инерционная преднастройка с антиципацией; (б) «контекст-рот» LLM = отсутствие сопряжённого торможения; (в) семь операций доминанты дают готовый протокол контекст-инжиниринга.

## 1. Один феномен, три масштаба

| Концепт | Масштаб | Ядро |
|---|---|---|
| Установка (Узнадзе) | мгновения | потребность × ситуация → преднастройка |
| Доминанта (Ухтомский) | минуты–часы | очаг + суммация + торможение + инерция + хронотоп |
| Контекст LLM | один вызов/сессия | attention weights по окну токенов |

Общий тезис всех трёх: **состояние системы определяет, что она увидит.**

## 2. Установка ↔ доминанта

Установка — «доминанта нулевого порядка»: целостное пред-сознательное состояние из взаимодействия потребности и ситуации [Узнадзе 1966; Tkemaladze 2025, DOI 10.65649/f74e8cca]. Доминанта — «установка с памятью и целью»: добавляет **инерцию** (переживает стимул) и **хронотоп** (антиципирует разрешение). Различие — не род, а **временна́я развёртка**.

## 3. Контекст-рот LLM = отсутствие торможения

Рост контекста ухудшает качество LLM из-за «noise accumulation and attention dilution», а не ёмкости [Wazir docs]; «attention becomes thinner across a longer input» [arXiv:2510.26493]. Это **отсутствие сопряжённого торможения**: модель не выделяет господствующий очаг и не подавляет конкурентов.

## 4. Семь операций как протокол контекст-инжиниринга

Перенос семи операций доминанты на контекст LLM:

- очаг → явная цель;
- суммация → ретрив релевантного (kb-hybrid);
- **торможение → паркинг/прунинг**;
- инерция → перенос цели между шагами;
- хронотоп → целевое состояние;
- собеседник → внешняя проверка;
- мета → наблюдение за фокусом.

Реализация — скилл `dominant` + плагин `@local/dominant` (живое состояние) + `sobesednik`.

## 5. Выводы

1. Узнадзе и Ухтомский описывают **один принцип** на разных масштабах; их современные «переоткрытия» (priming/task-set; salience/precision-weighting) — независимые подтверждения.
2. Проблема контекст-рота LLM — **инженерное выражение** той же задачи, которую доминанта решает биологически.
3. Семь операций — **проверяемый протокол контекст-инжиниринга**; его проверка на бенчмарках (длинный контекст + отвлекающие токены) — следующий шаг.
