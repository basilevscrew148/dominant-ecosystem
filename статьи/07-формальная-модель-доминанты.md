# Формальная модель доминанты (черновик, уровень D→C)

> Статус: рабочий черновик. Закрывает открытый вопрос «нет обучаемой математической модели доминанты». Исполняемая реализация — `ops/dominant-rs` (Rust, std-only), кросс-валидация с `ops/dominant_sim.py` (v1/v2) запланирована.

## 1. Переменные и уравнения

Пусть есть `n` очагов возбуждения (стимулов/каналов), шаг `t = 0,1,2,…`.

- `x_i(t)` — возбуждение очага `i` (может быть отрицательным — торможение);
- `s_i ∈ [0,1]` — «сырая» сила (salience) стимула;
- `g_i ∈ [0,1]` — сродство стимула цели (хронотоп-проекция);
- `goal` — индекс целевого канала (поставленный очаг).

**1.1 Precision-weighting** (гипотеза Радченко: доминанта = precision-weighting + инерция + антиципация [5]):

```
π_i(t) = π₀ + α · max(x_i(t), 0)        (точность канала растёт с возбуждением)
```

**1.2 Эффективный вход** (суммация + хронотоп-усиление + шум):

```
u_i(t) = π_i(t) · s_i · (1 + β · g_i · 𝟙[i = goal]) + ε_i(t),   ε_i ~ N(0, σ²)
```

**1.3 Динамика очага** (инерция + само-возбуждение + сопряжённое торможение + тяга хронотопа + насыщение):

```
x_i(t+1) = tanh( ρ·x_i(t) + w·max(x_i(t),0) + u_i(t) + γ·g_i·(T − x_i(t))·𝟙[i = goal]
                 − κ·max(x_L(t),0)·𝟙[i ≠ L] )
```

где `ρ ∈ [0,1)` — инерция (доля возбуждения, сохраняемая за шаг); `w` — само-возбуждение (свойство «повышенная возбудимость» по Шульгиной; бистабильность при `ρ + w > 1`); `κ` — сила сопряжённого торможения со стороны лидера `L = argmax x`; `γ·(T − x)` — тяга хронотопа к целевому уровню `T` (действует и после снятия стимула — антиципация); `tanh` — насыщение (биологический предел частоты разряда).

*Примечания реализации.* (а) Без насыщения линейная версия расходится из-за положительной обратной связи precision ↔ возбуждение — проверено на `dominant-rs` v0.1, служит самостоятельным аргументом за ограниченность очага. (б) Члены `w` и `γ` добавлены **по результатам кросс-валидации** с Python-симуляциями `dominant_sim.py` (там self_w = 1.2 даёт персистентность) и `dominant_sim2.py` (хронотоп тянет очаг после снятия стимула) — см. §3.6.

**1.4 Доминирование.** Очаг `L` объявляется доминантой, если

```
x_L ≥ θ   и   x_L − max_{i≠L} x_i ≥ δ     (порог + отрыв)
```

**1.5 Разрешение (хронотоп замкнулся).** Момент `t*` , когда доминанта совпала с `goal`; все подавленные стимулы попадают в **паркинг**.

## 2. Сопоставление с семью операциями (инвариант из [00-большая-статья])

| # | Операция | Формализация |
|---|---|---|
| 1 | Поставить очаг | выбор `goal` |
| 2 | Суммировать | накопление `ρ·x + u` |
| 3 | Затормозить конкурентов | `−κ·x_L` на всех `i ≠ L` |
| 4 | Держать инерцию | параметр `ρ` |
| 5 | Задать хронотоп | `β·g_i·𝟙[i=goal]` + критерий разрешения |
| 6 | Проверить собеседником | вне ядра: внешний «рецензент» сравнивает доминанту с целью (следующий слой, см. §5) |
| 7 | Мета-наблюдать | лог: кто доминанта на каждом шаге; событие «доминанта подменена» |

## 3. Проверяемые предсказания

1. ~~Латентность захвата монотонно убывает с `α`~~ — **ОПРОВЕРГНУТО симуляцией и уточнено** (см. §3.6): в дискретной модели с симметричным precision латентность от `α` не зависит или растёт; селекцию ускоряет сопряжённое торможение `κ`, а не precision сам по себе. Уточнённая форма: *при достаточном `κ` латентность захвата не зависит от `α`; при слабом `κ` высокое `α` препятствует объявлению доминанты (конкурент ускоряется симметрично, отрыв < δ).*
2. **Устойчивость доминанты требует `ρ + w` выше критического (= 1)**: при `ρ + w < 1` доминанта угасает после снятия стимула; при `ρ + w > 1` — удерживается сколь угодно долго. **Подтверждено (П2 PASS):** удержание после снятия стимула 1 → 140 шагов при росте ρ от 0.2 до 0.9 (w = 0.4, критическое ρ = 0.6).
3. **Хронотоп компенсирует низкую salience**: канал с малым `s_i`, но `g_i = 1`, выигрывает у сильного, но «чужого» стимула при достаточной инерции.
4. **Парковка монотонна**: число заторможенных стимулов не убывает, пока доминанта активна — формальный аналог «сопряжённого торможения» как журнала.
5. **Фазовый переход по `κ`**: существует порог торможения, выше которого доминанта становится «прилипчивой» (не снимается новым стимулом) — аналог патологической доминанты Ухтомского. **Подтверждено (П5 PASS):** дистрактор s=1.2 смещает доминанту в 5/5 сидов при κ ≤ 0.2 и в 0/5 при κ ≥ 0.4 — порог лежит в (0.2, 0.4).

**Содержательные итоги:** (1) модель дополнена двумя членами — само-возбуждением `w` (повышенная возбудимость, Шульгина) и тягой хронотопа `γ·(T−x)` — это и есть результат кросс-валидации; (2) гипотеза «доминанта = precision-weighting» уточнена: **precision-weighting сам по себе не ускоряет селекцию — она требует сопряжённого торможения**, что возвращает к исходной четвёрке свойств Ухтомского (precision — современный эквивалент повышенной возбудимости, но без торможения инвариант не работает).

## 5. Что НЕ покрывает модель (честные границы)

- Операция 6 (собеседник) — пока не формализована: требует второго агента/критика в контуре;
- этическая «интуиция совести» — вне вычислительной модели (см. открытые вопросы);
- обучение параметров — модель параметрическая, но не обучаемая; следующий шаг — подгонка по данным (`θ, κ, ρ` из поведения) или байесовская инверсия.
