# Формальная модель доминанты (черновик, уровень D→C)

> Статус: рабочий черновик. Закрывает открытый вопрос «нет обучаемой математической модели доминанты». Исполняемая реализация — `ops/dominant-rs` (Rust, std-only), кросс-валидация с `ops/dominant_sim.py` (v1/v2) запланирована.

## 1. Переменные и уравнения

Пусть есть `n` очагов возбуждения (стимулов/каналов), шаг `t = 0,1,2,…`.

- `x_i(t)` — возбуждение очага `i` (может быть отрицательным — торможение);
- `s_i ∈ [0,1]` — «сырая» сила (salience) стимула;
- `g_i ∈ [0,1]` — сродство стимула цели (хронотоп-проекция);
- `goal` — индекс целевого канала (поставленный очаг).

**1.1 Precision-weighting** (гипотеза Радченко: доминанта = precision-weighting + инерция + антиципация [5]):

```
π_i(t) = π₀ + α · max(x_i(t), 0)        (точность канала растёт с возбуждением)
```

**1.2 Эффективный вход** (суммация + хронотоп-усиление + шум):

```
u_i(t) = π_i(t) · s_i · (1 + β · g_i · 𝟙[i = goal]) + ε_i(t),   ε_i ~ N(0, σ²)
```

**1.3 Динамика очага** (инерция + сопряжённое торможение + насыщение):

```
x_i(t+1) = tanh( ρ · x_i(t) + u_i(t) − κ · max(x_L(t), 0) · 𝟙[i ≠ L] )
```

где `ρ ∈ [0,1)` — инерция (доля возбуждения, сохраняемая за шаг), `κ` — сила сопряжённого торможения со стороны лидера `L = argmax x`, а `tanh` — насыщение (биологический предел частоты разряда). *Примечание реализации:* без насыщения линейная версия расходится из-за положительной обратной связи precision ↔ возбуждение — это проверено на `dominant-rs` v0.1 и служит самостоятельным аргументом за ограниченность очага.

**1.4 Доминирование.** Очаг `L` объявляется доминантой, если

```
x_L ≥ θ   и   x_L − max_{i≠L} x_i ≥ δ     (порог + отрыв)
```

**1.5 Разрешение (хронотоп замкнулся).** Момент `t*` , когда доминанта совпала с `goal`; все подавленные стимулы попадают в **паркинг**.

## 2. Сопоставление с семью операциями (инвариант из [00-большая-статья])

| # | Операция | Формализация |
|---|---|---|
| 1 | Поставить очаг | выбор `goal` |
| 2 | Суммировать | накопление `ρ·x + u` |
| 3 | Затормозить конкурентов | `−κ·x_L` на всех `i ≠ L` |
| 4 | Держать инерцию | параметр `ρ` |
| 5 | Задать хронотоп | `β·g_i·𝟙[i=goal]` + критерий разрешения |
| 6 | Проверить собеседником | вне ядра: внешний «рецензент» сравнивает доминанту с целью (следующий слой, см. §5) |
| 7 | Мета-наблюдать | лог: кто доминанта на каждом шаге; событие «доминанта подменена» |

## 3. Проверяемые предсказания

1. **Латентность захвата монотонно убывает с `α`** (precision-weighting ускоряет селекцию) — измеримо прогоном `dominant-rs` с сеткой `α`.
2. **Устойчивость доминанты требует `ρ` выше критического**: при `ρ → 0` и шуме `σ > 0` время удержания доминанты падает до одного шага.
3. **Хронотоп компенсирует низкую salience**: канал с малым `s_i`, но `g_i = 1`, выигрывает у сильного, но «чужого» стимула при достаточной инерции.
4. **Парковка монотонна**: число заторможенных стимулов не убывает, пока доминанта активна — формальный аналог «сопряжённого торможения» как журнала.
5. **Фазовый переход по `κ`**: существует порог торможения, выше которого доминанта становится «прилипчивой» (не снимается новым стимулом) — аналог патологической доминанты Ухтомского.

## 5. Что НЕ покрывает модель (честные границы)

- Операция 6 (собеседник) — пока не формализована: требует второго агента/критика в контуре;
- этическая «интуиция совести» — вне вычислительной модели (см. открытые вопросы);
- обучение параметров — модель параметрическая, но не обучаемая; следующий шаг — подгонка по данным (`θ, κ, ρ` из поведения) или байесовская инверсия.
