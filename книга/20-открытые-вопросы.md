# Глава 20. Открытые вопросы и программа дальнейшей работы

## Открытые вопросы

1. **Формализация.** Нет обучаемой математической модели доминанты (есть качественная модель Крюкова; гипотеза Radchenko не верифицирована нейрофизиологически). Нужна модель «доминанта = precision-weighting + инерция + хронотоп» с проверяемыми предсказаниями.

2. **Верификация параллели с Фристона.** «Доминанта = точный аналог precision-weighting» — уровень D (гипотеза). Нужен эксперимент/симуляция, показывающие эквивалентность на конкретной задаче.

3. **Этика в коде.** Можно ли формализовать «доминанту на собеседнике» и «интуицию совести» как ограничения агента, или они принципиально феноменальны? Граница между логикой (переносится) и совестью (?) не установлена.

4. **Полнота инварианта.** Семь операций необходимы — но достаточны ли? Есть ли восьмая операция, которую доминанта делает, а инвариант упускает?

5. **Отрицательная новизна.** «На GitHub нет реализации» подтверждено поиском, но не исчерпывающе. Нужен систематический обзор (GitHub API) по ключевым словам: dominant, attention protocol, focus agent, interlocutor.

## Программа дальнейшей работы

1. Систематический prior-art обзор через GitHub API (закрыть вопрос 5).
2. Формальная модель доминанты как обучаемого агента (закрыть вопрос 1).
3. Развёртывание остальных глав книги (3, 4, 7, 8, 10, 12, 15, 19) до полного тома.
4. DSH-плагин (host) «доминанта»: не только скилл, но и состояние в профиле (текущая доминанта, паркинг) — перевести протокол из текста в живую панель.
5. Сборка EPUB/PDF книги и публикация серии.

## Честность о статусе

Эта книга — **рабочий манускрипт v1**: ядро (пролог, главы 1–2, 5–6, 9, 11, 13–14, 16–18, 20) написано, промежуточные главы покрыты статьями серии и будут дописаны. Уровни доказательности: параллель с Фристона — D (гипотеза), свойства доминанты и линия диалога — B/C (первоисточники и вторичная литература), сам инвариант — конструкт, требующий проверки (вопрос 4).

## Итог книги

Доминанта Ухтомского — **единая рамка** от физиологии внимания до логики агента. Её ядро — семь операций; её форма — холистическая экосистема из четырёх слоёв; её обещание — один принцип, который объясняет, *как держать фокус, притягивать нужное, тормозить лишнее, антиципировать, сверяться с собеседником и видеть себя*. Остальное — работа.
