# Глава 10. Антиципация: «модель потребного будущего» и акцептор результата

## Антиципация как отдельный механизм

Хронотоп (глава 9) — понятие. Антиципация — **механизм**, которым доминанта живёт во времени. У советской физиологии было два самостоятельных открытия этого механизма.

## Бернштейн: «модель потребного будущего»

Николай Бернштейн (биомеханика движений) показал: организм строит **модель целевого состояния до действия**, а движение лишь реализует эту модель. Рука тянется не «к предмету», а «к будущему положению предмета в моей модели».

Для доминанты это значит: **доминанта = целевая модель, предшествующая действию**. Она не «реагирует», а **предвосхищает**: очаг возбуждения уже содержит образ разрешения.

## Анохин: акцептор результата действия

Пётр Анохин (функциональные системы) добавил вторую половину цикла: **акцептор результата действия** — аппарат **сличения** ожидаемого результата с реально полученным. Если совпало — система завершает цикл; если нет — запускается коррекция (или ориентировочная реакция).

Полный цикл по Анохину:

**афферентный синтез → принятие решения → программа действия → акцептор результата → действие → обратная афферентация → сличение.**

Это ровно цикл доминанты, дополненный **обратной связью**: доминанта не только антиципирует (Бернштейн), но и **сверяет** предвосхищение с результатом (Анохин).

## Сведение к доминанте

| Механизм | Автор | Операция доминанты |
|---|---|---|
| модель потребного будущего | Бернштейн | операция 5 (хронотоп) |
| акцептор результата | Анохин | операция 7 (сличение/мета) |
| афферентный синтез | Анохин | операции 1–2 (очаг + суммация) |
| программа действия | Анохин/Бернштейн | операции 3–4 (торможение + инерция) |

Весь цикл Анохина — **доминанта в развёрнутом виде**. Ухтомский дал «очаг», Бернштейн дал «будущее», Анохин дал «сличение»; вместе — полный механизм.

## Современный аналог: predictive coding

Predictive coding (Friston) описывает тот же цикл: мозг **предсказывает** вход, сверяет с реальностью, минимизирует **ошибку предсказания**. Разница только в акценте: predictive coding — о минимизации ошибки, советская линия — о **достижении цели**. Доминанта объединяет оба: ошибка и цель — два полюса одного цикла.

## Итог

Антиципация — не «добавка» к доминанте, а её **рабочий механизм во времени**: модель будущего (Бернштейн) + сличение с результатом (Анохин) = predictive coding с целью. Для агента это операция 5 (хронотоп) и операция 7 (мета-сличение).
