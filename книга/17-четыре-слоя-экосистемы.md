# Глава 17. Четыре слоя экосистемы (холистика)

## От инварианта к экосистеме

Семь операций — инвариант. Экосистема — это инвариант, **развёрнутый в четыре слоя**, где каждый инструмент — частный случай доминанты.

| Слой | Назначение | Что входит |
|---|---|---|
| **1. Метод (теория)** — «почему» | обоснование | статьи серии + эта книга |
| **2. Логика (промпты/скиллы)** — «как» | протокол действий | скиллы `dominant`, `sobesednik`; библиотека промптов |
| **3. Инструменты (код)** — «чем» | исполнение | существующие + новые скиллы/плагины |
| **4. Опыт (экосистема)** — «каково» | целостность | экосистемная карта, глоссарий, путь пользователя |

## Холистический принцип

Сила экосистемы — **не сумма инструментов, а их взаимное усиление через один инвариант**. Каждый инструмент — частный случай доминанты, поэтому они не конфликтуют, а складываются:

- `kb-hybrid` = **суммация** (операция 2);
- `six-hats-panel` / `six_hats` = **режимы** доминанты;
- `recursive-thinking` = **инерция/итерация** до аттрактора;
- `verify-claims` + `sobesednik` = **собеседник** (операция 6);
- `session-contract` / `reflection` = **хронотоп** (прошлое→будущее);
- `dominant` = **весь протокол** (1–7).

## Как это ощущается (опыт)

Пользователь входит с вопросом и движется по одному циклу:

**вход (цель) → суммация (поиск) → исследование/письмо (удержание) → собеседник (проверка) → фиксация (заметка+Anki) → мета-шаг (что было у руля).**

На каждом шаге «рулит» один инструмент, но все говорят на одном языке доминанты — поэтому переходы бесшовны.

## Почему холистика, а не «пакет фич»

Отдельные плагины решают отдельные задачи; экосистема решает **одну задачу на всех уровнях** — «держать фокус, притягивать нужное, тормозить лишнее, антиципировать, сверяться с собеседником и видеть себя». Это и есть холистический подход: **целое первично, инструменты вторичны**.

## Итог

Экосистема — не инвентарь, а **архитектура**: четыре слоя, один инвариант, один опыт. Следующая глава даёт инвентарь и путь пользователя.
