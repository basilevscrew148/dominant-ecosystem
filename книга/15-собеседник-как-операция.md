# Глава 15. Собеседник как операция обзора

## Из этики — в регламент

Операция 6 инварианта — «проверить собеседником». Как превратить её из принципа в **повторяемый регламент**? Ответ — конкретный протокол обзора.

## Протокол (5 шагов)

1. **Сформулировать проверяемую доминанту** — главный тезис одним предложением. Без него критика беспредметна.
2. **Prior art** — «кто уже это сделал/писал?»: поиск в базе (`kb_search`/`kb_semantic`), в сети, на GitHub (`web_search`, GitHub API). Фиксировать уровень уверенности («не нашёл» ≠ «не существует»).
3. **Критические роли** — применить внешние позиции:
   - **Скептик** — слабейшее звено, натяжка;
   - **Иноверец** — как опроверг бы оппонент из другой парадигмы;
   - **Новичок** — что недоказано/непонятно постороннему;
   - **Двойник-детектор** — где автор выдаёт желаемое за действительное.
4. **Фактчек** — числа, имена, DOI/ссылки сверять с источником (`verify-claims`).
5. **Вердикт** раздельно: (а) подтверждено, (б) гипотеза, (в) «Двойник», (г) неизвестно.

## Реализация в экосистеме

Протокол реализован трояко:

- **скилл `sobesednik`** — полный протокол как вызываемый инструмент;
- **промпт `собеседник-рецензент`** — copy-paste версия для разового обзора;
- **шаг 4b в `research-pipeline`** — встроенная проверка перед публикацией заметки.

## Связь с другими операциями

- Собеседник **замыкает** цикл с мета-наблюдением (операция 7): обзор выявляет, была ли подмена доминанты.
- Собеседник **не заменяет** суммацию (2) — он проверяет *выводы* суммации, а не собирает материал.
- Собеседник **отличается** от шести шляп: шляпы — параллельные *режимы* одной доминанты; собеседник — *внешняя* позиция, разрывающая самоподтверждение.

## Границы и ловушки

- **Ложный собеседник**: агент, который «соглашается с поправками» — это Двойник в маске. Признак настоящего собеседника — он меняет **направление**, а не только формулировки.
- **Общая слепая зона**: два собеседника одной парадигмы могут ошибаться одинаково. Лекарство — намеренно иная парадигма (иноверец).
- **Перфекционизм**: один проход собеседника — минимум, не повод для бесконечного ревью.

## Итог

Собеседник — **самая переносимая в код операция** из семи: она уже работает как скилл, промпт и шаг пайплайна. Это практическое ядро этики Ухтомского в экосистеме.
